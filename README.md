# Agent 工坊

一个本地运行的 AI 产品规划与项目检查工具。输入一句话点子或一份需求文档，整理产品需求、推导架构方案与组件选型，再配合 AI 编程工具完成代码骨架和后续迭代。

## 主要功能

- **从想法到方案**：梳理需求与待确认问题，输出 PRD、架构方案和组件选型建议。
- **检查已有项目**：结合需求文档与项目源码，生成包含证据、缺失项和改进优先级的差距报告。
- **管理产品迭代**：按产品保存需求版本、方案、代码骨架与迭代记录，支持新增需求后的持续更新。
- **对话式操作**：提供本地网页界面，也支持通过命令行或能够读取本地文件的 AI 编程工具使用。

基本流程：**想法 → 需求与方案 → 确认 → AI 编程工具实现 → 检查与迭代**。

项目包含 Python 引擎、React + TypeScript 网页界面，以及 17 个 Agent 组件参考实现，覆盖工具调用、记忆、上下文管理和多 Agent 协作等能力。
